## 🌟 Tính Năng Chính
1. **Luyện thi Trắc Nghiệm (~100 câu):**
   - Bộ 1: 50 câu OOP (Kế thừa, Đa hình, Abstract class, Interface).
   - Bộ 2: 25 câu Trắc nghiệm nền tảng Java & Giao diện Swing/AWT.
   - Bộ 3: 15 câu Trắc nghiệm phân tích Code Snippet.
   - Chấm điểm tự động và giải thích chi tiết đáp án Đúng/Sai ngay lập tức.
   - Lọc các câu làm sai để luyện lại.
   - Nút xáo trộn câu hỏi ngẫu nhiên.
2. **Sổ Tay Tự Luận & Code Analysis:**
   - Đầy đủ các câu hỏi lý thuyết cốt lõi (final, super, this, static, String Pool, try-catch-finally...).
   - Tìm kiếm câu hỏi tức thì qua thanh Search.
3. **Vấn Đáp Lập Trình CSDL & Android:**
   - Quy trình nạp và thực thi Bytecode của JVM.
   - Mô hình MVC.
   - JDBC khóa tự tăng và PreparedStatement.
   - Hibernate trong NetBeans.
   - Android Options Menu, Context Menu, Dialogs.
4. **Giao diện Responsive & Dark Mode:**
   - Tối ưu hiển thị trên cả điện thoại di động và máy tính.
   - Hỗ trợ chế độ Sáng / Tối.
